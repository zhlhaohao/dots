# 02 — 长按编辑格子

**What to build:** 在九宫格上长按任意格子（含空格子）弹出「格子编辑」对话框：可修改标题与 URL，可把格子清空为空格子（两个字段都留空即空格子）。保存后九宫格立即反映修改，且写入手机本地用户配置——杀进程重进后修改仍在；修改全程无需重新编译或重装 App。

**Blocked by:** 01 — 出厂配置 + 九宫格渲染 + 单击打开。

**Status:** ready-for-agent

- [ ] 长按非空格子弹出编辑框，预填当前标题与 URL
- [ ] 长按空格子同样弹出编辑框（预填为空）
- [ ] 标题与 URL 均留空保存 → 该格子成为空格子（灰显、不响应单击）
- [ ] 保存后九宫格立即刷新，无需重启 App
- [ ] 修改持久化到用户配置：杀进程重进后修改仍在
- [ ] 对 URL 输入做基本校验（空或非法时提示，不产生打不开的入口）
