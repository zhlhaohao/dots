# 04 — 拖拽排序

**What to build:** 在九宫格上长按并拖动任意格子（含空格子）即可调整其在 3×3 网格中的位置，其余格子实时让位预览；松手后新顺序立即生效并持久化到用户配置——杀进程重进后顺序不变。注意与「长按弹编辑框」的手势分工（如长按起拖、长按静止弹框，或采用其他不冲突的分发方式）。

**Blocked by:** 01 — 出厂配置 + 九宫格渲染 + 单击打开（与 02/03 无真实依赖，可并行）。

**Status:** ready-for-agent

- [ ] 长按拖动可移动任意格子，拖动中有让位预览
- [ ] 空格子同样可拖动换位
- [ ] 松手后顺序立即生效，且持久化：杀进程重进后顺序不变
- [ ] 拖拽手势与长按编辑手势不互相误触
- [ ] 单击打开行为在排序后仍指向正确的格子条目
