# 01 — 出厂配置 + 九宫格渲染 + 单击打开

**What to build:** 冷启动 App，Splash 跳转后看到的不再是纯欢迎页，而是 3×3 九宫格启动台：欢迎语保留为页面标题，每个格子以「标题首字母色块 + 标题」的卡片呈现，空格子灰显占位。单击非空格子即在宿主页面打开该格的 URL；出厂九宫格中包含演示页入口（JSBridge 演示链路保持可达）。首次启动把随包内置的出厂配置拷贝为手机本地的用户配置，之后每次启动读取用户配置渲染；用户配置 JSON 损坏时回退出厂配置，应用不崩溃。

**Blocked by:** None — can start immediately.
